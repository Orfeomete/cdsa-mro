# Preregistration documents

These documents were frozen as local files before the runs they govern and were never deposited in a public registry,
so they carry no independent public timestamp. The SHA-256 digests in `SHA256SUMS.txt` were computed on 14 October 2026
from the archived copies. They show that the texts are unchanged from that date on, not when they were written. Where an
addendum was appended to a preregistration, the digest covers the original text and the addendum together.
